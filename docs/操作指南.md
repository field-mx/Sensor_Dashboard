# 操作指南

“电解槽AI监控系统”用于结项展示，可回放Excel数据、预测未来96秒、演示突高/突低预警，并在本机更新模型。

1. 双击`StartDemo.cmd`，点击“导入数据”，再点“播放”。可暂停、重置和调整倍速。
2. 在“监测与预测”选择测点。积累96秒历史后显示预测；选择故障通道、幅度和持续时间，点击“注入突高”或“注入突低”。“停止注入”后等待残差恢复，可查看或导出事件历史。
3. 点击“模型更新”，选择或拖入正常Excel；校验通过后勾选正常数据声明并登记，开始后训练。训练完成后，在“模型版本”验证候选，通过后可激活，也可回滚。
4. 需要每日训练时，在“每日后训练”开启开关、设置时间并保存。没有新数据会跳过。关闭界面后需保持本机后台运行；停止后台双击`StopBackend.cmd`。
