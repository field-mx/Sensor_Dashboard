# 电解槽多传感器监控系统操作指南

## 项目介绍

本项目用于在电脑上接收和显示工业制氢设备的传感器数据，并将数据保存为 Excel 文件。

## 主要功能

- **工况总览**：查看氧气、氢气、两路温度和两路压力。默认真实采集时，温度和压力显示为 mA 电流值。
- **槽电压监控**：查看16路电压及 PT100 温度，展开查看趋势曲线。
- **数字孪生**：查看电解槽三维示意模型，点击传感器点位查看数值。页面初始含示例值，需等待实际数据更新。
- **数据保存**：将新接收的数据保存为 Excel。

## 操作步骤

### 1 启动程序

电脑安装 Python 3.11 后，在项目文件夹中打开终端，执行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

依赖只需首次安装。采集设备需向本机 IP 发送数据：工况使用 UDP 9090，PT100 温度使用 UDP 9091，电压使用 UDP 9092。

无设备时，可使用模拟模式体验：

```powershell
python main.py --source mock
```

### 2 查看数据

点击左侧菜单切换页面。在“槽电压监控”中，点击通道右侧箭头展开曲线，点击“V”或“°C”切换电压与温度。通过“工况总览”的最近更新时间确认数据是否持续更新。

### 3 保存数据

点击左下方“选择保存位置”，指定一个新的 Excel 文件名，再点击“开始保存”。结束时点击“停止保存”，等待完成提示。每次记录使用新文件名，避免覆盖旧数据。

### 4 退出程序

停止保存后，关闭监控窗口即可。
