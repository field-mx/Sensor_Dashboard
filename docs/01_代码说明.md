# 电解槽多传感器监控系统代码说明

## 项目概述

本项目是 Python 桌面监控程序，使用 PyQt6 构建界面、pyqtgraph 绘制曲线和三维模型、openpyxl 保存 Excel。主要功能为工况总览、16路电压与温度监控、数字孪生展示和数据记录。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `main.py` | 程序入口，创建窗口、连接数据源和记录器，设置监听端口 |
| `backend/network_receiver.py` | 接收 UDP/TCP 数据，解析报文，处理通道映射和数值换算 |
| `backend/data_manager.py` | 转发实时数据，管理内存历史缓存 |
| `backend/mock_generator.py` | 生成模拟数据，供无设备演示使用 |
| `backend/excel_recorder.py` | 后台保存 Excel，处理开始和停止记录 |
| `frontend/main_window.py` | 主窗口、页面切换、保存按钮和状态栏 |
| `frontend/view_process_overview.py` | 六项工况数值、状态和趋势 |
| `frontend/view_voltage.py` | 16通道电压与温度、曲线展开和切换 |
| `frontend/view_digital_twin.py` | 三维示意模型、传感器点位和建议展示 |
| `frontend/styles.py` | 界面样式和配色 |
| `requirements.txt` | 主程序依赖 |

`view_3d.py` 和 `history_dialog.py` 为保留的旧界面，当前主窗口未使用。`data/`、`pc_receive_logs/`及随附 Excel 为历史资料，启动时不会自动读取。

`udp(3).py` 是独立的48路 ADC 诊断工具；`udp(3) copy.py` 增加电流换算和10分钟分段保存。它们使用相同监听端口，应与主程序分开运行。

## 数据流程与端口

```text
采集设备 → network_receiver → data_manager → 监控页面
                                         → excel_recorder → Excel
```

默认由电脑监听，采集设备主动向电脑 IP 发送数据：

| 端口 | 接收内容 | 对应页面 |
| --- | --- | --- |
| UDP 9090 | AD7616 二进制工况数据 | 工况总览 |
| UDP 9091 | PT100 CSV 温度数据 | 槽电压监控 |
| UDP 9092 | AI CSV 电压数据 | 槽电压监控 |

接收器也支持 JSON 帧。TCP 模式只监听主端口，按每行一个 JSON 帧接收，不额外开启 UDP 9091、9092。

默认真实工况中，氧气、氢气由电流换算为浓度，两路温度和两路压力仍为 mA 电流值；PT100 温度独立接收，单位为 °C。数字孪生启动时含示例数据，页面主要负责展示，不包含实际设备控制。

## 启动方式

建议使用 Python 3.11，在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

模拟演示：

```powershell
python main.py --source mock
```

修改监听端口：

```powershell
python main.py --source udp --port 9090 --temperature-port 9091 --voltage-port 9092
```

`--host` 默认是 `0.0.0.0`，表示监听本机全部 IPv4 网卡。

## 数据保存与维护

点击界面“开始保存”后，记录新收到的数据，生成“记录信息”“电压温度”“六通道传感器”三张工作表。电压和温度分别成行；无效 PT100 温度可能写为0。同一路径重新开始记录会覆盖旧文件。

常见修改位置：通道映射与换算修改 `network_receiver.py`，显示范围和阈值修改对应页面，Excel 列和保存逻辑修改 `excel_recorder.py`，界面配色修改 `styles.py`。
