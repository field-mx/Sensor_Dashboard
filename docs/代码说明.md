# 代码说明

软件由PyQt6桌面界面和本机FastAPI服务组成，默认只访问`127.0.0.1:18000`。真实训练与验证运行在独立Python进程中。

| 目录 | 用途 |
|---|---|
| `sensor_demo/` | Excel导入、按源时间回放、异步预测、故障注入、残差预警、三维示意和模型更新窗口 |
| `sensor_demo/presentation.py`、`sensor_demo/assets/` | 软件名称、图外图例及随包离线Logo；素材来源见assets/SOURCES.md |
| `demo_server/` | 真实PRCTF推理、数据准入、训练任务、候选验证/激活/回滚和每日调度 |
| `demo_tools/` | 独立环境安装、交付校验和打包 |
| `configs/` | 56通道顺序、冻结预警校准、候选验证门槛、配置示例 |
| `vendor/` | 固定版本PRCTF及ChannelTokenFormer源码、工业权重和发布清单 |
| `sample_data/` | 原始展示Excel，只读 |
| `tests/`、`evidence/` | 开发检查与实际操作验收记录 |

模型使用原始单位，输入96秒×56通道，输出未来连续96秒×56通道；标准化由公开预测器负责。其余5个测点仅展示观测。报警比较已提前生成的对应时刻预测与当前观测，连续3点超限触发、5点正常恢复。

训练数据必须单独导入、校验并声明正常，按时间60%/20%/20%分区。小预算真实微调产生独立候选，评估通过后手动激活。运行数据写入独立用户目录，不覆盖公开权重或原实用版。
