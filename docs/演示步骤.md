# 可重复的结项演示

1. 双击`StartDemo.cmd`，确认标题为“电解槽AI监控系统”、本机模型已连接；导入随包Excel。
2. 打开“监测与预测”，选择`TT010301`，速度10×，点击播放。积累96点后，说明观测、已对齐预测、未来96秒预测三条曲线。
3. 故障通道选`TT010301`，幅度20、持续12秒，注入突高。观察曲线变化、连续3点残差超限后的预警；继续播放，等待连续5点有效正常后恢复。
4. 注入突低，必要时点击停止注入。异常仍会影响后续96秒历史，解除需要等待残差恢复。打开事件历史，筛选通道，查看触发/恢复时间并导出CSV。
5. 暂停回放，打开“模型更新”。将正常Excel从左侧文件列表拖到右侧，或选择文件。查看61测点/56模型通道及时间分区，勾选正常数据声明并登记；默认登记后开始5轮真实后训练。已登记同文件可在后训练任务页选择并手动开始。
6. 观察真实轮次、loss和耗时；完成后到模型版本页验证候选。通过则激活并返回监控继续预测；未通过则展示拒绝原因，保留旧模型。可回滚到公开基线。
7. 每日后训练默认关闭；开启、设置时间并保存，观察下一次执行。点击立即检查：原数据已经处理则明确跳过。真实前端退出后的近时调度证据见`evidence/task10.md`；演示结束关闭每日开关并保存。
8. 点击重置，确认当前回放曲线和事件清空；可再次开始。退出界面后后台继续运行；结束展示时双击`StopBackend.cmd`。

已有历史数据可能用于基线训练；此次展示说明功能闭环，不宣称独立故障准确率或后训练一定提升。任务记录和候选权重按真实结果保留。
